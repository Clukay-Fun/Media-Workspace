# 封面时间越界复现

基线 dev `2b04f78294a9f0dbc247bda86d18c10ad82a7321`，使用独立的真实测试工程：主轨 813 帧、30 fps（27100 ms），封面 `atMs=33500`。

修改前运行 `mw cover <工程> --out <新文件>` 返回 `ok: true`、`frame: 1005`，退出码 0。`compile(coverView(project))` 返回 `durationInFrames=813`；`renderStills` 将请求帧限制在 0–812，实际渲染第 812 帧（约 27066.67 ms）。封面入口返回的是请求帧，而非渲染器实际夹取的帧，因而静默成功。

修改后，同一工程运行上述命令返回 `TIME_RANGE`、退出码 1，指出 33500 ms 和主轨时长 27100 ms，建议重新选择时间；预先写入目标文件的标记内容保持不变。`mw lint` 给出 `COVER_OUT_OF_RANGE`。字体检测还提示缺少字幕字体，该提示与封面越界无关。

字幕与封面标题行数都使用 `estimateLines` 的字号、字距、最大宽度估算；中文按一个字号宽，其他字符按近似比例，不测真实字体。截断警告给出估计被截掉的文本，实际排版可能有差异。
