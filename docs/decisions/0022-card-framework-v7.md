# 0022：卡片框架和干净封面（格式 v7）

日期：2026-10-30。

## 背景

阶段 E（0021）要加一批 MG 卡片，由 Codex、DeepSeek 分头写模板。动手前要先定好几件所有卡片共用的事，
否则每个模板各写一套：

1. 卡片有大有小。小卡只占一块；半屏卡占下半屏，这时主画面要往上让，不然人脸和卡片挤在一起；全屏卡盖住整个画面。
2. 卡片的底板、进出场应该一致，看起来是一套。
3. 截图卡片要用图片素材，模板组件拿不到素材地址（渲染时只把时间线上用到的素材换成地址）。
4. 封面：`mw cover` 把字幕、标题、卡片都截了进去，样片的封面是干净画面加一条大标题；
   `cover.title` 引用一个叠加层 ID，但渲染时没有用上，而且那个叠加层还会出现在视频里。

## 决定

**格式 v7**：

- 叠加层新增可选的 `size: "small" | "half" | "full"`。不写时用模板的默认尺寸（`meta.sizes` 第一个），默认尺寸不能是 `half`：
  半屏卡要让主画面让位，必须显式写出来，免得 AI 不知道画面会动。
- `cover.title` 从叠加层 ID 改成直接写 `{ template, style?, props }`。迁移时按 ID 把那个叠加层的模板、样式、内容抄过来，
  找不到就去掉；原来的叠加层留在视频里不动。

**半屏让位**：compile 把半屏卡出现的时间段合并成 `mainShifts`（重叠、相接的合成一段，中间不回落），
主轨和字幕在这些时间段里整体上移画面高度的 15%，进出各 400ms 缓入缓出。

- 先定 25%，用 1080×1920 截图看，人脸会被推出画面顶部，改成 15%。卡片占 52%–92% 的高度，字幕上移后正好在人脸和卡片之间。
- 字幕跟着上移：只移主画面的话，字幕（中心约 61% 高度）会压在卡片中间。
- 画中画、图片、其它叠加层不动，它们是 AI 自己摆的位置。
- 质检跟着算：挡脸检查里人脸位置减去上移量；字幕按让位时间段切开，各段用各自的位置判断遮挡；
  审片台点选框也按当前帧上移。

**模板约定**（`src/templates`，写法见 `docs/template-guide.md`）：

- `TemplateProps` 新增 `size`（实际尺寸）和 `src(assetId)`（素材地址）。模板在注册表里用 `assets(props)` 声明用到的素材，
  渲染时只把这些素材换成地址，校验时检查素材存在、类型对。
- `meta` 统一成 `TemplateMeta`：`sizes`、`mood`、`useFor`（什么内容用这张卡）、`example`（一份能用的 props）。
  `mw guide` 原样输出，AI 按它选卡片。
- `card.ts`：`cardBox(size)` 给出三种尺寸的区域，`inCard` 把文字样式放进卡片；`CardFrame` 画底板、统一进出场
  （320ms 从下面浮上来、轻微放大，200ms 淡出）。组件和 `bounds` 用同一套计算，质检和画面一致。
- 通用测试（`templates/index.test.ts`）：每个注册的模板自动检查 meta 写全、默认尺寸不是半屏、`example` 能通过 schema、
  每个尺寸的占位都在画布里（竖屏、横屏各一次）。

新增一个通用模板 `text-card`（标题 + 正文，三种尺寸都支持）和内置样式 `card-white`，既能直接用，也是写新卡片的参考。

**封面**：`coverView` 从工程里只留主轨，加上封面标题（从第 0 帧显示到主轨结束），截 `atMs` 那一帧。
字幕、画中画、图片、其它叠加层、片尾都不要。标题从第 0 帧开始显示，所以 `atMs` 不要小于入场动画的时长（1 秒以上就够）。

## 测试

- 单测：迁移 v6 → v7；半屏时间段合并和上移曲线；封面只留主轨和标题；字幕上移后不再和半屏卡重叠，小卡照样报重叠；模板通用检查。
- 导出测试：半屏卡上移中、上移后的帧截图和导出一致；上半屏在半屏卡和小卡时确实不同、半屏卡出现前相同；
  封面和「只有主画面 + 标题」的截图一致，和完整画面在下半屏明显不同。

## 待定

上移比例、卡片区域、进出场时长是按截图定的初值，等 Grok 的卡片调研出来再调（都集中在 `core/compile.ts` 的
`HALF_CARD_SHIFT` 和 `templates/card.ts`）。
