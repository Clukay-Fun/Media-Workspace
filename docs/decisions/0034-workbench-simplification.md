# D34：简化工作台显示并停用账号参考线

状态：2026-11-09 负责人确认。

## 决定

1. 视频时间线片段只保留色块和必要的剪辑标记，不显示文件名、倍速、连续画面缩略图或视频波形；悬停也不显示文件名。音频波形及非视频片段的文字仍保留。
2. 画布选中框去掉长名称，保留元素类型、锁定标记和质检问题标记；选中、拖动和缩放行为不变。
3. 停用账号级参考线：工作台不显示或编辑账号版式中的 `guides`，CLI/MCP 的 `preview --guides` 只叠加当前工程 `editor.json` 的构图参考线。为兼容已有 `layout.json`，旧 `guides` 字段仍可被读取和原样保存，但不参与预览。账号版式的人脸位置、倍速、字幕字数和样式设置继续使用。本决定取代 D27 中账号参考线的显示与编辑约定，以及 D30 中横屏隐藏账号参考线的约定。
4. 动画改动由用户验收通过后才能提交。这条规则适用于所有执行者，不按模型固定分工；执行与独立审查按具体任务确定。

## 验收

- 时间线横向滚动时工具栏保持可见，底部滚动条可操作；视频块不再生成连续缩略帧或视频波形。
- 选中标题、字幕、图片或画中画时仍能看到类型和必要状态，元素的拖动、缩放和右侧属性不受影响。
- 账号版式编辑器不再提供参考线操作；旧版式仍能载入，`preview --guides` 只显示工程构图参考线。
