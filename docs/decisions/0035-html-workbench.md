## 决定

1. 播放器采用 `播放器_浅色精简版_V7.html` 的浅色播放器及底栏；右侧按选中对象切换字幕、标题、视频和默认项目属性。五份用户提供的 HTML 是本次界面结构与视觉的依据。
2. 保留顶部工程标题与切换、素材导入、视频导出，以及播放器的参考线与标尺。素材入口移至顶栏，通过浮层导入本机路径、查看现有素材并放到画面。
3. 移除工作台底部时间线、左侧素材栏、审阅页签、AI 改动页及顶部 AI 改动提示。批注继续从播放器的进度条与画面入口操作；CLI/MCP、工程历史和原有底层编辑能力保留。
4. 视频页采用五个裁切比例缩略图，速度和音量使用滑杆与数值框。滑杆显示设计稿的常用区间，数值框仍允许既有工程支持的速度 0.1–10、音量 −60 至 +20 dB。打开面板、只聚焦并离开滑杆均不得夹改既有数值；实际修改后才提交。
5. 文字页采用顶部四页签、修改范围单选、字体下拉、纵向参数行和五列动效预设。字体选项继续标明来源、可导出状态和授权登记。仅支持工程字段能够实际保存的参数；斜体、删除线、整体混合透明度、保持音调等能力不伪装为可用。
6. 默认项目页按草稿参数与时间线参数显示真实信息。名称与保存路径只读；当前可修改画幅为 9:16、16:9，取消不写入，完成后沿用 `core/aspect` 一次提交并换算工程参考线。不新增工程字段，不伪造草稿编辑能力。
7. 新增 `POST /api/import`，使用共享请求 schema、当前工程上下文与 `node/actions.importAsset`。UI 导入保留版本检查、原始文件只读、缓存和历史规则，切换工程后不将旧导入结果显示到新工程。
