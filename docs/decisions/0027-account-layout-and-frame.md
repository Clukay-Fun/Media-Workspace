# 0027：账号版式和 `mw frame`

日期：2026-10-31。属于阶段 F（0025）。

## 背景

阶段 E 验收的四份片子人物位置各不相同：参考线只存在工程的 `editor.json` 里（只给工作台看），AI 和渲染都不读，
AI 只能自己估主画面的缩放和位置。用户的参考线是账号级的：所有片子人物都摆在同一个位置。

## 决定

- **账号版式** `~/MediaWorkspace/library/layout.json`（`core/layout.ts`）：`guides`（参考线，横 / 竖、位置占画面比例、名字）、
  `face`（人脸框该落在哪：中心 x、上沿 y、下沿 y，占画面比例）、`titleStyle` / `captionStyle`（样式名）。
  比例而不是像素，横竖屏、不同分辨率共用一份。读写：`mw layout [--file]`、MCP `layout`、`GET / PUT /api/library/layout`。
  不进工程文件，工程格式不变。
- `face` 用人脸检测框（Vision，不含头发）表示，和 `mw frame` 用的是同一种框，量和用不会有系统误差。
  在样片 1029 上量用户自己的成片：人脸框中心 x 50.6%、上沿 35.9%、下沿 50.5%，下沿和参考图上「下巴」那条线（51.3%）一致。
- **`mw frame`**（MCP `frame`）：读主轨片段素材的人脸数据（没有就先检测），每个采样取最大的脸、各边取中位数，
  算出让人脸框落到 `face` 上的缩放和位置（和渲染一致：先 contain 居中，再以中心缩放、移动）。
  至少放大到盖满画面、不挪出边缘，宁可脸偏大、偏一点也不露黑边（返回 `clamped`）。同一素材的片段用同一套取景，
  有关键帧的片段不动。在样片上算出缩放 1.27，用户自己剪的是 1.265。
- `preview --guides` 同时叠加账号版式和工程自己的参考线。
- 工作台：画面上默认显示账号参考线（青色、带名字）；预览设置里勾「编辑账号版式」后可以拖线（松手保存），
  在面板里改名字、精确数值（百分比）、增删参考线，改人脸位置（画面上显示成虚线框）。改的是账号版式，所有工程都跟着变。

## lint 按账号版式检查

- `FACE_OFF_LAYOUT`（警告）：每个主轨片段按人脸中位数和片段的缩放、位置算出人脸在画面上的位置，
  和版式的 `face` 比：横向或上沿偏 2.5% 以上（约 27px / 48px，比用户成片里的波动大两倍）、大小差 10% 以上就报，提示跑 `mw frame`。
- `STYLE_NOT_LAYOUT`（提示）：版式规定了字幕 / 标题样式，工程里用的不是它。
- 有账号版式时，`TEXT_OUTSIDE_SAFE_AREA` 降为提示（`level: "hint"`）：位置以用户自己的版式为准，
  通用安全区只作参考。工作台顶栏的数字和时间线标记只算警告，提示在审阅栏里用浅色列出。
