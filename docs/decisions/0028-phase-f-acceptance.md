# 0028：阶段 F 验收

日期：2026-10-31。属于阶段 F（0025）。

## 验收方式

新开的 Claude Code、Codex、Grok 会话，各给同一句话：只有原片和一段纯文本文稿（没有字幕文件），
用 `pnpm mw` 出一条口播成片——指定两行顶部标题、「按账号设置出片」、接默认片尾、导出成片和封面，
做完用 `mw compare` 和用户自己剪的成片对比。提示词里故意不写倍速、只剪头尾、摆人物、不加卡片，看 AI 能不能照规则和账号设置做对。

## 结果

三份都合格，而且结果几乎一样：都用了账号的 1.1 倍速、只剪头尾空白（句中停顿保留）、`frame` 摆人物
（三份算出的缩放和位置相同）、不加卡片；`validate` 通过，`lint` 只剩两条 hint（照用户样片量的标题条、字幕略出通用安全区）。
识音认错的字都按文稿改回；`check` 为空。Claude Code 和 Grok 还读了 `splitLines`，把断在词中间的行用 merge + split 调过。
和用户的成片比：时长差 0.48 秒（开头、结尾各多剪了一点），人脸位置平均差约 1.8% 画面宽；
字幕是 20 条一行，用户的是 16 条、长句折成两行。

## 发现的问题和修改

1. **导入后不会放上主轨**（三份都提到）：`transcribe` 读主轨，要先手动 `item.add`，规则里没写。
   `import` 视频时主轨空着就整段放上主轨，倍速按账号设置（返回 `mainClip`）；`--no-main`（MCP `main: false`）只导入。
   `outro` 导入片尾素材时不放主轨。
2. **剪头尾切掉最后一个字的尾音**（Claude Code、Grok）：响度阈值判定的说话结束比尾音早，留 120ms 不够。
   `--edges` 默认头尾各留 300ms（用户自己剪的片子大约这么多），并且不剪进第一句字幕之前、最后一句字幕之后。
   复验：入点、出点和用户的成片差 30ms 和 0ms。
3. **改断行要三步**（Claude Code）：merge、split，再 update 去掉行尾顿号，`caption.update` 改字还会丢掉逐字时间。
   - 新 op `caption.reflow { ids, lines }`：相邻几句按给定的几行一步重排，字要和原来一样（标点可以不同），逐字时间跟着字走；
   - `caption.split` 断开后前半句末尾的标点（顿号、逗号）不显示；
   - `caption.update` 改了文字时，没改的字保留原来的逐字时间，新加、换掉的字插值（以前是整个丢掉）。
   只是新操作和行为修正，工程格式不变，不升版本。
4. **字幕可以折成两行**（用户确认）：账号版式加 `captionMaxChars`（一条最多几个字，`null` = 按样式每条一行），
   用户的设置是 14：比一行（10 字）长的折成两行。`transcribe` 按它断句，不超过样式允许的行数；工作台的账号版式面板里可以改。
   折行时句中有顿号、逗号这类标点、在标点后面折开两边都放得下，就在标点后面折，不按词边界均分。
   账号版式文件（`library/layout.json`）的新字段有默认值，旧文件照常读，不升版本。
5. **命令的小问题**：`init`、`outro` 可以写 `--actor`（以前记成 user）；`outro` 的 `changed` 写上片尾素材（以前是空的）；
   `export` 的 `seconds` 其实是渲染耗时，改名 `renderSeconds`，另给成片时长 `durationMs`；`mw <命令> --help` 不再报「不认识的命令」。
6. **规则**：用户已经写明标题、要求直接出片时照用，不停下来问；有账号版式时安全区 hint 的提示不再建议改 maxWidth。
7. **`mw compare`**：
   - 新增 `timing`：两边的响度包络做相关，估出参考成片从原片哪里开始、几倍速（假设中间没剪），和工程主轨对照。
     在样片上估出的起点、倍速和人工测量一致；
   - 字幕按这个对应关系去参考成片里取同一处的帧；参考成片断句不同、对不上工程的字时，直接取字幕那一带识别出的文字，
     能看出参考那边是怎么断的；`differences` 只列不一样或没法比的，一样的放在 `same`；
   - 加一张 6 处同一时刻的并排小图（`comparisonSheet`）；
   - 参考成片里没对上的画面变化，开头 300ms 内的标「标题等出现，不是剪辑」，和片尾长度对得上的标「接片尾」。

## 复验

按同样的提示词走一遍（`F-recheck`）：`import` 自动上主轨（1.1 倍速）→ `transcribe`（17 条，最多 14 字）→
一处 `caption.reflow` → `remove-silence --edges` → `frame` → 标题、封面 → `outro` → `lint`（两条 hint）→ 导出。
成片 28.57 秒，用户的 28.71 秒（差的主要是片尾叠化）；起点差 30ms、倍速相同；人脸位置平均差约 1.3% 画面宽。
用户成片多出的那一条差别：一句算上顿号 15 个字，超过 14 字被拆成两条，用户那边是一条。

## 没做的

- 标题字体和用户的不同（账号版式的 `titleStyle` 还是空的），后续优化。
- `compare` 的 `timing` 只按整段线性对齐，参考成片中间有剪时只对前面一段准。
