# 0010：浅色工作台，章节和剪辑理由（工程格式 v4）

日期：2026-10-29。修订 0009 第 2 点（布局）。

## 背景

三栏布局试了几版，用户还是觉得不顺手，说不清什么样的界面「适合人看、适合 AI 驱动」，
给了老萨工作台的截图作参考（`~/Desktop/1029/老萨工作台`，只看界面思路，不涉及代码）。
那套界面顺手的原因有三条：

1. 能点的不用写：卡型、九宫格位置、开关都是可视化控件，点一下就改好。
2. 和 AI 说话的输入框就在属性面板底下，说的就是当前选中的东西。
3. AI 做了什么直接画在时间线上：粗剪掉的地方标「重录 / 口误 / 废句」，上方有流程步骤，预览顶上有章节条。

我们之前的问题正好相反：质检、改动、批注都是要逐条读的文字列表，选中元素后能改的东西大多也只能写批注。

## 决定

1. **版式**：浅色、卡片式。上面三栏——左栏素材 / 样式，中间预览（顶上章节条），右栏属性 / 批注 / AI 改动；
   下面是整宽时间线。顶栏中间是工程进度（导入 → 字幕 → 粗剪 → 章节 → 标题 → 导出），从工程内容推断，
   第一个没做的标成「下一步」；AI 刚改过时换成改动提示。
2. **属性页能点就点**：样式是色块卡片，位置是五档示意图（顶部 / 上方 / 中间 / 下方 / 字幕区，对应 `slot`），
   语速是分段按钮，时间微调是图标。点不出来的在底部输入框「告诉 AI 要改什么」，自动带上选中的元素和时间点。
   没选中时属性页是章节目录和质检问题；质检不再单独占一页，同时标在时间线和章节条上。
3. **时间线**：轨道按用途命名（主视频、字幕、标题、画中画、音频），带图标和颜色，不再有精简模式。
   主视频轨上把 AI 粗剪的理由标在剪口处（红色标签）。
4. **工程格式升到 v4**，新增两个可选字段，都由 AI 写：
   - `MainClip.cutBefore`：这一段前面剪掉的内容为什么剪（口误、重复、停顿，16 字以内）。
     分割片段时只留在前半段。
   - `Project.chapters`：`[{ title, at }]`，`at` 是锚点（建议锚到每章第一句字幕，剪辑后跟着走）。
     用 `chapters.set` 整体替换。锚点被剪掉的章节不显示，并给出警告。
   旧工程没有这两个字段，界面就不显示章节条和剪辑理由；迁移只改版本号。
