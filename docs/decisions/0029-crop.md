# 0029：素材画面裁切（工程格式 v8）

## 背景

主轨视频、画中画视频和图片需要保存素材画面裁切。裁切必须随工程保存，并在预览和导出中一致生效；已有 `transform`、关键帧和动画继续作用于裁切后的画面。

## 决定

- `crop` 是素材源画面上的归一化矩形：`{ x, y, width, height }`，原点在素材左上角，范围为 0–1。
- `x`、`y` 是左上角；`width`、`height` 必须大于 0，且 `x + width`、`y + height` 不能超过 1。裁切不受片段 `inMs` / `outMs` 影响。
- 主轨视频、普通视频片段和图片可以有 `crop`；音频片段不能有。省略 `crop` 表示完整素材。`item.update` 的 `set.crop: null` 清除裁切。
- 渲染顺序是：按 `crop` 截取素材 → 将可见区域按原有 `contain` 规则居中放入画布 → 应用现有变换、关键帧和动画。裁切后不拉伸素材。
- 裁切矩形在操作入口校验，非法值（越界、宽高为 0 或负数、未知字段）返回 `INVALID_OP`。裁切需要素材的探测宽高；没有尺寸时校验返回 `CROP_DIMENSIONS`。

## 迁移

v7 → v8 只升级 `version`，不改片段或图片数据。旧工程没有 `crop`，所以继续完整显示原素材；不写入默认全尺寸矩形，避免无意义改写历史工程。

## 几何影响

`core/crop.ts` 提供裁切后的可见框、媒体偏移和裁切后尺寸，并把源坐标的人脸框裁到可见区域。lint 的画面遮挡、人脸遮挡和账号版式检查、`frame` 摆人物、`compare` 人脸位置比较都复用这些坐标语义。

`src/web/` 不属于本批修改范围。界面接入时，选中框和点选命中应使用编译时间线上的 `crop` / `sourceSize`，并调用 `cropLayout(canvas, sourceSize, crop).box`；不要继续对整素材调用 `containBox`。裁切窗口还应按 `cropLayout(...).media` 的偏移和尺寸显示素材。

## MCP 示例

```json
{
  "op": "item.update",
  "id": "clip-1",
  "set": { "crop": { "x": 0.1, "y": 0.15, "width": 0.8, "height": 0.7 } }
}
```

这表示从素材左侧取 10%、顶部取 15%，保留素材宽度的 80% 和高度的 70%。主轨、画中画、图片都使用同一字段。恢复完整画面：

```json
{ "op": "item.update", "id": "clip-1", "set": { "crop": null } }
```
