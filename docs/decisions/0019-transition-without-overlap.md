# 0019：主轨转场不占时间；图片和画中画从画面外滑入

日期：2026-10-30。阶段 D 验收（样片 1029）时用户的反馈。

## 背景

1. 转场原来用 Remotion 的 `TransitionSeries`：后一段提前开始，两段在转场时长内重叠，总时长变短。
   口播的剪辑点在句子交界，重叠的 300ms 里前一句最后一个字和后一句第一个字同时出声，用户听着别扭。
2. 图片和画中画的「滑动」只挪一小段（按字号的参考尺寸），看起来像在原地抖一下，不像从画面外滑进来；
   视频层还只用了动画的透明度。
3. 呼吸幅度 ±3% 看不出来；推近 4 秒偏慢。

## 决定

1. **主轨转场不占时间**：后一段照常接在前一段后面，总时长不变；转场时长内，后一段底下垫着前一段停住的最后一帧
   （`<Freeze>`，静音），按 fade / slide / push 过渡。声音直接硬切，一个字都不丢。
   接片尾的转场保持重叠（片尾一般没有人声）。工程格式不变，但加过转场的工程总时长会变长（每个转场多出它的时长）。
   不再使用 `@remotion/transitions`，三种过渡的画面由 `transitionStyles` 自己算，新画面始终在上面。
2. **图片和画中画的 slide 从画面外进出**：位移取画面宽 / 高；没写 `direction` 时从最近的画面边缘进出
   （右上角的小窗从右边进来、往右边出去，`outwardDirection`）。文字的 slide 不变。
3. 呼吸在界面上默认 `intensity: 2`（±6%）；给 AI 的说明里推近改成 1.5–2.5 秒。
4. 主轨、画中画、图片的 `Sequence` 提前 1 秒预加载（`premountFor`），减少预览播放到新素材时的停顿。

## 验证

单测：转场不改变片段位置和总时长；`outwardDirection`；`slide` 给了画面宽高时起点在画面外。
导出测试改成 120 帧，转场中、转场后的帧截图和导出一致，slide 和 push 画面不同。
样片验收工程重新导出：转场帧里旧画面停住、新画面从右边盖上来；小窗从右边滑进来。
