# 0015：右栏属性改回可视化编辑，分工和编辑范围

日期：2026-10-30。部分推翻 0011 第 3 条（样式编辑面板 F5 不做）。

## 背景

阶段 C 时定过「样式细节交给 AI，界面只负责挑选、套用、存模板」。实际用下来，用户希望常用参数能直接在右栏改：
字幕的字体、颜色、位置、动画，主视频的变速和音量，图片的大小和位置。需求分析在本地笔记
`local/notes/2026-10-30-properties-panel/`（带参考截图，不进仓库）。

## 决定

1. **右栏按元素类型拆文件**：`src/web/components/inspector/` 下每类一个文件——
   `caption.tsx`（字幕）、`caption-list.tsx`（全部字幕列表）、`overlay.tsx`（标题 / 卡片）、
   `clip.tsx`（主轨片段、画中画、音频）、`image.tsx`（图片），公共控件在 `common.tsx`，`index.tsx` 按类型分发。
   几个 AI 同时开发时各改各的文件（分工见 `docs/STATUS.md`）。
2. **编辑范围**（`core/style-scope.ts`）：几句字幕常常共用一个样式。
   - 默认只改选中的这一句：第一次改时复制出它专属的样式（`<原样式>-<元素 ID>`），之后一直改这份，不会每改一下多一个样式；
   - 「应用到所有用这个样式的」才改共享样式；
   - 内置样式没复制进工程时先复制。界面用 `inspector/common.tsx` 的 `editStyle`，CLI / AI 以后也用同一个函数。
3. **只露出常用项**：字幕先露出文字、模板、动画、字体字号、颜色、位置；描边、阴影、背景框、发光收进折叠区。
   更细的仍交给 AI。控件只在松手 / 确认时提交一次操作。
4. **模板不另建库**：右栏「存为模板」用现有的样式模板库（`/api/library/styles`）；动画预设不单独建库。
5. **这次不做**：整句斜体、文字弯曲、音频淡入淡出、图片蒙版、组合 / 循环动画、曲线变速。需要时另开决策，先扩 schema 再做界面，不做假控件。
6. **声音分离**先做本地可行性实验（结果写在 `local/notes/`），效果确认后再定模型、格式和界面。
7. 项目概览里显示保存路径：服务端已知工程目录，加到项目接口里；色彩空间不显示。
