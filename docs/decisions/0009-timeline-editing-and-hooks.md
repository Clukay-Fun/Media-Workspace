# 0009：审片台加回时间线拖动和分割；对话 hook 接批注

日期：2026-10-29。修订 D28（`0008-review-console.md`）。

## 背景

用户看了审片台后提出：时间线上的块要能像剪映一样拖动、裁剪，要有分割；布局改成左边面板加时间线、右边整列视频，
分隔条都能拖；撤销 / 重做放到时间线工具栏。另外批注写在审片台里，对话里的 AI 不会主动知道。

## 决定

1. **时间线上直接做**：拖块移动、拖两端裁剪、在播放头处分割（⌘B）、吸附到字幕边界和播放头（工具栏开关，拖动时按住 ⌘ 临时关闭）。
   计算全部用 `core/edit` 里已有的 `planDrag`、`planSplit`，界面只换算像素和提交 ops；松开时提交一次（D23）。
   不做多轨插入、拖进拖出、跨轨移动。
   拖主轨片段等于剪掉说话内容，跟着这段的字幕和叠加层会一起动，这是锚定的正常行为。
2. **布局（同日几经调整，最后定为三栏）**：左栏是选中 / 样式 / 素材三页（选中元素的详情：改字、时间微调、样式、锁定；
   样式库和素材带搜索）；中间上预览、下时间线（同宽，播放控制在时间线首行、和画面中线对齐）；
   右边审阅栏是问题 / AI 改动 / 批注三页，批注输入框固定在底部。中途试过把选中详情并进审阅栏、去掉样式库和素材，
   用下来还是三栏分开方便。时间线默认精简（标记、AI 改动、画面段落），展开后才是完整轨道和拖动编辑。
   AI 改动按版本记「待确认」（确认到哪一版存在浏览器里），时间线上紫色标出。
   断点按容器宽度：≥1280 左栏 300、审阅栏 340；1024–1279 为 260 / 300；900–1023 左栏变抽屉；
   650–899 两边都是抽屉（同一时间只开一个）；<650 整屏切换。地址带 `?embed` 时不显示工程名。
   尺寸存在浏览器里，双击分隔条恢复默认。
3. **对话 hook**：`mw hook prompt` 给 Claude Code 和 Codex 的 UserPromptSubmit 用（两边都认 `hookSpecificOutput.additionalContext`），
   每次发消息时附上正在审的工程（`mw serve` 记在 `MW_HOME/serving.json`）里的新批注；附过的只提数量；没有就不输出。
   想让 AI 一直等，用 `mw comments <工程> --wait`，出现新批注才返回。
4. **贴纸（SVG 动画）**这次不做：数据模型、渲染都还没有，单独排期。

## 影响

- PLAN 第 3 节 v0.8 调整里，分割、裁剪从「写批注交给 AI」移到「界面上直接做」。删句、去停顿、变速等仍交给 AI。
