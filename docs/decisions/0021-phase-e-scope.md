# 0021：阶段 E 盘点和分工

日期：2026-10-30。

## 背景

阶段 E 的范围是 MG 卡片（F12）、封面导出（F18）、给 AI 的编排规则和 `mw guide`，
验收是在 Codex 和 Claude Code 里各说一句话（剪停顿、顶部标题、居中黄高亮字幕、第二个观点用半屏卡、接默认片尾、导出封面），
AI 自己走完 `inspect → apply → validate → preview --sheet → export`。开工前逐项核对：

| 项目 | 现状 | 缺口 |
|---|---|---|
| MG 卡片 | 只有 `title-bar` 一个模板；模板约定（schema / component / bounds / meta）已定，meta 里预留了 sizes、mood | 7 类卡片都没有；没有小卡 / 半屏 / 全屏的尺寸约定；半屏卡出现时主画面上移没有；模板用不了图片素材 |
| 封面 | `mw cover` 导出 `cover.atMs` 那一帧 | 字幕、顶部标题都截进去了（样片封面是干净画面 + 一条大标题带）；`cover.title` 没有用上；工作台没有入口 |
| 默认片尾 | 片尾要先导入素材再 `outro.set` | 没有「默认片尾」 |
| 编排规则 | 先列方案、自查、批注、样式、画面 | 没有卡片怎么选；「第几个观点」怎么定位 |

## 决定

先由 Claude 搭卡片框架，Codex 和 DeepSeek 按同一套约定写模板：

- **Claude**（dev）：卡片框架——卡片尺寸（叠加层的 `size`，格式升版本）、半屏卡时主画面上移、
  卡片外框组件和占位计算、模板可以引用图片素材；封面改成「干净画面 + 封面标题」；默认片尾；编排规则；最后的验收。
- **Grok**（`local/notes/`，不写代码）：调研口播里小卡、半屏卡、全屏卡的样子和参数，半屏时主画面怎么让位，财经 / 移民类常用哪几种卡。
- **Codex**：第一批模板——金句、要点列表、大数字滚动。
- **DeepSeek**：第一批模板——人名条 / 提示条、截图卡片（用图片素材）；工作台的封面入口。

图表（柱状 / 折线 / 占比）和标志出场放到第二批。模板只借鉴 Barty-Bart motion-graphics（MIT）的分类，不用代码。
