# 0023：默认片尾

日期：2026-10-30。

## 背景

阶段 E 的验收要在一句话里「接默认片尾」（0021）。以前接片尾要先 `import` 片尾视频，再写 `outro.set` 操作，
AI 要知道片尾文件在哪；CLI 和 MCP 也没有专门的片尾命令。同一个账号的片尾基本固定，每条视频都一样。

## 决定

- 默认片尾记在 `~/MediaWorkspace/library/outro.json`（`MW_HOME` 下，和样式模板库同一层）：视频文件的绝对路径、
  接上去的转场（默认叠化 300ms，`null` = 硬切）、音量。**只记路径，不复制文件**：片尾原文件只读，
  接到工程里时照常导入，标准化文件放进工程的 `cache/`。
- `mw outro-default [文件] [--fade ms] [--gain db]`：不给文件时显示当前设置，给了就设置。只有人用，AI 不改默认片尾。
- `mw outro <工程> [文件] [--fade ms] [--remove]` 和 MCP 的 `outro` 工具：不给文件用默认片尾；没设置时报 `NOT_FOUND`，
  提示人去设置。工程里已经导入过同一个文件就直接用那个素材，不重复导入；新导入的素材 ID 优先用 `outro`。
  `fadeMs` 不写时用默认片尾的设置，`0` = 硬切。
- 格式不变：工程里还是 `outro: { asset, transitionIn, gainDb }`，换了默认片尾不影响已经接好的工程。

## 测试

- 单测：没设置时报 `NOT_FOUND`；文件不存在不能设置；已经导入过的文件直接复用，叠化、音量按默认设置；`fadeMs: 0` 硬切。
- 导出测试：导入一个片尾文件接上，时间线上片尾从主轨结束前 300ms 开始；再接一次不重复导入；去掉片尾。
