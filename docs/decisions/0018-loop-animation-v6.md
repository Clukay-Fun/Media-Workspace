# 0018：图片和画中画的循环动画（格式 v6）

日期：2026-10-30。对应阶段 D 第二批（`docs/decisions/0017`）。

## 背景

阶段 D 的 F8 要求图片有入场、出场、循环动画。渲染层的 `elementState` 早就支持循环（文字样式在用），
但图片和视频片段没有地方写循环动画，渲染时一直传 `null`。
转场和循环动画的调研结论是：口播里贴图常用的循环只有「呼吸」（轻微放大再缩回，周期约 2.4 秒、幅度 ±3%），
浮动、摇摆、Ken Burns 不常用，真要用可以用关键帧。

## 决定

1. 图片（`ImageItem`）、主轨片段和普通轨道片段新增可选字段 **`animLoop`**，结构和 `animIn` 一样，
   但 `preset` 只能是 `none` 或 `breathe`；`durationMs` 是一个周期。工程格式升到 **v6**，
   迁移只改版本号（新字段可选，旧工程不用改）。
2. 审片台的图片和画中画属性里加「循环动画：无 / 呼吸」，默认周期 2400ms。
   动画设置抽成 `inspector/anims.tsx`，图片和画中画共用。
3. 顺带修了视频层：之前只用了动画的透明度，画中画的「弹出」「上移」只会淡入淡出。
   现在图片和视频用同一个函数叠加动画的位移、缩放、旋转、透明度、模糊。

## 不做

其它循环预设（浮动、摇摆、慢推）。只开放呼吸，以后要加时扩 `LoopAnim` 的枚举即可，不用再升版本。

## 验证

单测：迁移 v5 → v6、`animLoop` 传到时间线、非呼吸的预设被 schema 拒绝。
导出测试的画中画加了「弹出」入场和呼吸循环，动的几帧上截图和导出一致。
