# 0004：阶段 A 验收记录（样片 1029）

日期：2026-10-28 · 状态：自测通过，等待用户确认成片效果

## 做法

只用 CLI，从 `剪辑前.mov` 复刻 `剪辑后.mp4`（工程和渲染结果在临时目录，不进仓库）：

```bash
mw init 1029
mw import 1029 ~/Desktop/1029/剪辑前.mov --id raw
mw import 1029 ~/Desktop/1029/片尾.mp4 --id outro
mw apply 1029 --base 2 --actor claude --ops ops.json   # 见下
mw validate 1029
mw guides 1029 --add v:536,h:483,h:986,h:1167,v:106,v:965,h:189,h:1728
mw preview 1029 --at s9 --guides --safe-area
mw preview 1029 --sheet 8
mw export 1029
```

`ops.json`：主轨片段 `{ asset: raw, inMs: 2607, outMs: 32380, speed: 1.1, transform: { scale: 1.266, x: 542, y: 970 } }`，
`outro.set`，`caption.import`（`timebase: "timeline"`，用样片的 SRT），`title-bar` 叠加层（`durationMs: "toEnd"`）。
字幕和标题用 `mw init` 自带的内置样式 `caption-word-yellow`、`title-bar-yellow`。

## 过程中发现并修正的问题

- 0001 里记录的水平位移是错的（+11px → +2px）。
- `mw apply --ops -`（从 stdin 读）被参数解析器当成缺少参数值；参数错误没有按退出码 2 返回。
- 渲染时会加载所有内置样式的字体，导致测试依赖普惠体；改为只加载实际用到的样式。
