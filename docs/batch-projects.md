# 批量生成审片工程

`pnpm mw batch <manifest.json>` 按清单逐项建立可继续编辑的 `.mwproj` 工程，并在 `MW_HOME/batch-reports/` 下为每项写一份 JSON 报告。这个命令不会导出 MP4，也不会修改账号版式或默认片尾。

## 清单格式

路径相对于清单文件所在目录。`captionStyle`、`titleStyle` 必须是样式库中已有的 ID；字体由样式引用，不复制字体文件。片尾可以用当前账号默认片尾，或清单目录中的文件；`fadeMs` 必须明确填写，`0` 表示硬切。

```json
{
  "version": 1,
  "template": {
    "captionStyle": "1029-caption-puhui-v1",
    "titleStyle": "1029-title-puhui-v1",
    "outro": { "file": "accountDefault", "fadeMs": 0 }
  },
  "items": [
    {
      "projectName": "默认模板-样片-A",
      "video": "剪辑前.mov",
      "scriptFile": "script.txt",
      "titleLines": ["主标题", "副标题"]
    }
  ]
}
```

界面中这两套样式显示为“默认模板字幕”和“默认模板标题”。清单仍使用样式库 ID `1029-caption-puhui-v1`、`1029-title-puhui-v1`；这些 ID 是已有工程和样式库的兼容标识，改显示名称不会更改它们。

每项要提供唯一的 `projectName`、视频、纯文本 `scriptFile` 和正好两段 `titleLines`。批量预检先按样式库保存的画布把标题样式适配到新建的 9:16 工程，再估算总行数；超过两行的项目会被拒绝并在报告中记录估算值，不会创建工程。估算沿用 `core/lint.ts` 的 `estimateLines`：中文字符按字号宽度估算，其他字符按较窄的平均宽度估算。

浏览器实际排版依赖字体字形、字距和文字平衡换行，估算可能和真实预览略有差异。报告会保留 `titleEstimate` 便于复核；仍须预览确认标题实际两行及安全区位置。纯文本是校字依据；报告会保留识音结果和文稿差异，供人工检查。命令按模板样式生成字幕，以实际首条字幕锚定标题，并让标题在主轨内容结束时消失。只剪片头片尾静音，保留句中停顿；取景调用现有 `frame`，使用账号版式计算人物位置。

## 安全与报告

已有同名工程不会覆盖。单项失败会记录失败步骤并继续处理后续项目。每份报告包含生成步骤、最终 revision、校验与 lint 结果；出现 lint 提示时仍需人工查看预览和报告。批量流程不代表审核通过。

建议先在隔离的 `MW_HOME` 里试跑：复制所需样式到该目录的样式库，并配置测试用账号版式与默认片尾，避免碰真实工程和共享设置。
