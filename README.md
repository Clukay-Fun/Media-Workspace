# Media Workspace

本地运行的 AI 原生口播编排工作台：AI 通过 CLI / MCP 修改结构化工程，人在本地网页里预览、微调、导出。

- 开发计划：[docs/PLAN.md](docs/PLAN.md)
- 开发规范：[AGENTS.md](AGENTS.md)
